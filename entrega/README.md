# Baixar e testar a apostila

- **Apostila-Claude.html**: apostila completa em um arquivo, com aulas, exercícios, guia por texto/voz e comparação ilustrada entre Cowork e Claude Code.
- **Apostila-Claude-projeto.zip**: código-fonte e instruções de execução.

No GitHub, abra o arquivo escolhido e use **Download raw file** (ícone de download) para salvá-lo. Abra o HTML baixado em um navegador moderno.

O reconhecimento de voz depende do suporte do navegador, do microfone e da permissão concedida. A busca por texto também está disponível.

Esta entrega oferece arquivos para download; ainda não há um site publicado.
